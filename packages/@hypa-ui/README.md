# `@hypa/ui`

Shared UI package scaffold for Hypa products.

Current structure:

- `@hypa/ui/web`: web-only UI primitives and product-facing components
- `@hypa/ui/mobile`: mobile-only UI primitives and product-facing components
- `@hypa/ui/shared`: UI utilities or components safe to share across web and mobile

This package is intentionally scaffolded only. It is not wired into any app yet.
